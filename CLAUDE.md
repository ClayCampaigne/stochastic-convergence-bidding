# Project Notes

## Development Environment
- This is a UV project - use `uv run` for executing Python scripts
- Main script: `uv run run_project.py`
- Dependencies managed through `pyproject.toml` and `uv.lock`

## Project Structure
- Main optimization script: `run_project.py`
- Core modules in `stochastic_convergence_bidding/`
- Results stored in `results/` directory
- Data files in `data/` directory
